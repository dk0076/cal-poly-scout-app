scout_vsm

v1 scouting

Read any opponent off their own coordinates.

Drop .vsm or .dvw files for a scouted opponent — typically the matches you have on them. Every attack, serve and set in a VolleyStation .vsm carries a true contact-to-landing trajectory, and a DataVolley .dvw carries the same two points when it was coded with ball positions, so hitting direction, serve target and set origin come straight out of the data instead of being inferred from zone codes. A file coded without positions still gives every count, percentage, rotation and phase split; only the courts stay empty. Files for different opponents can be loaded in the same session; use the focus-team picker above to switch which team's numbers you're looking at.
